# Cua candidate audit — 2026-09-11

The shared macOS desktop backend remains disabled. No action family has been certified to leave the user's physical cursor, keyboard, focus and clipboard untouched. `server/cua_driver.py` exposes read-only capability metadata and explicitly requested window inventory; its restricted action gate is internal and defaults to empty. There is no PyAutoGUI or foreground fallback. This audit is not a claim that all applications support safe background AX input.

## Adapter contract and validation

`await capabilities()` never starts a native process and returns `available=false`, `agent_cursor_available=false`, `physical_input_untouched=false`, `tested_actions=[]`. `await list_windows()` starts and reaps its own hash-verified direct MCP child only for an explicit inventory request. Its environment disables telemetry and update checks and selects standard permission mode. Returned records contain `pid`, `window_id`, `app_name`, `title`, `bounds`, `is_on_screen`.

`CuaDriver(pid, window_id, *, enabled_actions=())` refuses missing/invalid selected-window identity, mismatched screenshots, incoherent coordinate transforms, stale tokens, pixel coordinates, unknown native controls and unadmitted actions. Pause interrupts the owning stdio process rather than just abandoning a waiting request; unknown timeout outcomes are fatal, and resume starts a new context. No model-supplied script, selector, executable, PID or clipboard operation is accepted as an action.

Actual evidence: `artifacts/cua-source-review/window-inventory-verification.json` records successful read-only listing (6 windows, expected fields). This checks transport/schema only; it is **not** a concurrency proof. `tests/test_cua_driver.py`: 13 injected-message tests passed, covering scope identity, retina mapping, disabled actions, stale invalidation, malformed frames, exact token dispatch and cancellation. These are **not native input tests**. Existing native smoke artifacts exercise the legacy foreground driver and cannot validate the co-working product.
