# Public validation evidence

[public-validation.json](public-validation.json) is generated by the release validation command, not copied from a historical claim. It records the environment, dependency versions, selected commands, exit codes, privacy/static-check summary, source manifest digest and machine-readable test counts.

## What the public checks mean

Selected Python tests use synthetic data and mocked provider responses. Frontend tests run a real headless Chromium browser against an isolated mock API. A frontend pass establishes that specified UI contracts held in that fixture; it is not a successful real-model computer task. No cloud credential or real model is used.

## Historical model baselines

The retained development documents report a legacy small-model baseline of 0/6 tasks and a later Hermes profile evaluation of 0/2 tasks. Those different evaluations are not combined. Their raw local artifacts were not present in the uploaded repository, so they are explicitly maintainer-recorded historical results, not independently reproduced evidence in this release. The previously documented 1021 passed / 1 skipped suite is likewise not substituted for the newly executed, narrower public checks.

Older links to ignored `artifacts/`, `output/` or runtime files are rendered as local-only references. Nothing has been generated to impersonate those missing originals.

## Reproduce

Use the commands in [README](../../README.md), or run `python scripts/validate_public_release.py` after installing the locked dependencies and the frontend Chromium browser. The validator returns nonzero if one of its required checks fails. Its report defaults to the ignored `artifacts/public-validation.json`.

Only reviewed, de-identified summaries belong here. Raw logs, screenshots, task transcripts, browser profiles and session databases remain excluded.
