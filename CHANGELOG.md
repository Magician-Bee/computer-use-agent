# Changelog

## 0.1.0-public.1 — 2026-09-16

Public source preview, not a production-readiness release.

- Add an explicit MIT license for original code, third-party notices, contribution guidance and a security reporting policy.
- Present a public-facing README with installation recipes, current support boundaries and an evidence index.
- Retain source privacy checks and sanitized portable home paths; keep private runtime outputs excluded.
- Align Anthropic and Gemini frontend endpoint defaults with the backend adapters.
- Remove external font-loading links from the workspace shell.
- Make local-only historical evidence references explicit instead of presenting broken report links.
- Add selected source/provider/storage checks and isolated frontend validation, with machine-readable evidence and read-only CI.

No claim is made that native desktop certification, full Hermes/workspace integration, restart recovery or general real-model task reliability is complete. The exact validation outcomes accompany the released source.
